## 실제 캡처에서 확인한 시각적 구성
1. 1600px 화면에 가로 3영역: 좌측 문서함 및 PDF 파일 선택/원본 뷰, 중앙 새 디자인 A4 미리보기, 우측 디자인/모델 상태 설정. 최상단 파일 저장·기존 편집 이동과 01–04 단계 표시.
2. 한국어 인터페이스 글꼴 정상. 실제 합성 원본 PDF 페이지가 좌측 작은 PDF 뷰에 보이고 같은 원문 텍스트가 중앙에서 **다르게 재조판**됨. 화면의 모델 미설치 메시지는 사실에 맞음.
3. 명백한 UX 차이: 원본 뷰는 폭 약 340px 제한 좌측 카드 내의 작은 iframe이며 블록 클릭→원본 페이지 좌표 이동/동시 강조는 없음. 중앙 뷰는 A4 폭 중심 스크롤이며 **인쇄 페이지 나눔의 정확한 페이지별 WYSIWYG가 아님**.
4. 상단 01–04는 `Workspace.tsx`의 `nav > span` 텍스트이며 **조작 가능한 단계 탭/마법사가 아니다**. STEP3 PDF는 현재 `input[type=file]`로 선택, 드래그앤드롭 미구현. 좁은 창에서 2열/1열 CSS는 있지만 실제 사용성은 별도 사용자 테스트 필요.
5. 라디오에 4가지 테마가 표시되나, **실제 인쇄 조판 차이를 자동 실측으로 검증한 것은 보고서형/미니멀형 2종**이다. 4개 표기=4개 상업 검증 템플릿이 아니고 8/20/30종 완성이 아니다. 캡처 1장으로 디자인 전체 사용성을 확정하지 않는다.
