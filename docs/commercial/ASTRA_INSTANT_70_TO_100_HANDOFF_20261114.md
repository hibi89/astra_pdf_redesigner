## 4. 100점 판정의 강제 차단 조건

1. 공식 100점은 사용자 최종설계 전체 12영역 인수와 법적·상용 조건이 충족돼야 가능하다. 잠정 100/100과 정식 판매 GO는 같은 뜻이 아니다. 검증 없는 100점 선언 금지.
2. A11의 실사용 허가 PDF 5~10건(7점), A12 실제 권리·판매·최종 승인(2점), A01/A02/A10 실제 사용자 PC·파일 최종 검수 점수는 사용자가 자료·동의를 제공하기 전에는 자동으로 획득할 수 없다.
3. 고객 실제 PDF, 개인 데이터, 모델 가중치, Windows 공급자 설치파일 등 대용량은 GitHub에 직접 커밋하지 않는다. 결과 해시/재현 문서/합성 fixture 및 코드만 저장소에 반영한다. 사용자 원본은 로컬, 요청 시 ChatGPT Library 저장. 고객 동의 없이 업로드·외부 전송 금지.
4. 출시/판매/고객용 license 활성화, 판매자 키 생성·보관·배포, 신규 유료 API·도메인·외부 원본 전송, 인증/보안/권한 변경은 사용자 별도 승인 필수. 기존 RELEASE HOLD·OCR_MANIFEST=null·공개키 pin=null 유지.
5. 모델 재배포권·한국어 윤문 정확도·OCR DLL 공급처와 법무 증거, 실제 물리 Windows10/11 검증이 없으면 CI SUCCESS만으로 성능/법적 출시 합격 처리하지 않는다.
