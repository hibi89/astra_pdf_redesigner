## 크몽 복사 초안 — 아직 게시하지 말 것

**제목 제안:** 내 PC에서 PDF 원문 대조·디자인 변경·A4 새 파일 제작 | ASTRA

**한줄 소개:** 사용자가 허가한 텍스트 중심 PDF를 로컬에서 열고 원문과 재디자인 결과를 검토해 새로운 A4 PDF를 만듭니다. 내용·표·이미지는 문서별 확인이 필요합니다.

**핵심 설명:**
1. PDF 불러오기: 지원/미지원 위험 사전 고지, 원본 확인 후 가져오기 승인.
2. 원본 내용 검수: 본문·숫자·이미지·표/다단 의심 및 누락 위험 표시, 사람이 확인한 내용만 편집.
3. 디자인 적용: 검증된 A4 레이아웃 선택, 별도의 결과 PDF로 저장. 원본 PDF 덮어쓰기 금지.
4. 출력 확인: 원본과 출력 PDF의 해시·숫자·읽기 순서·그림/벡터 수 위험 신호 및 실제 7항목 육안검사.

**지원범위 고지:** 선택 가능한 텍스트가 있는 PDF 중심, PDF 30MiB/최대 50페이지 검사 기술 상한은 **판매 성공 보증 범위가 아님**. 스캔·암호/DRM·복잡한 표와 다단은 변환 전 별도 확인 필요. 사용 중 원본·고객 문서를 자동 서버 업로드하지 않도록 설계.
