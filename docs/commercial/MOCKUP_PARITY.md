# ASTRA 목업 vs 실제 앱 — 따라 만드는 우선순위표 (초기 기준)

기준: 2026-10-25 채팅에서 생성한 'ASTRA PDF Redesigner' 프로모션 콘셉트. 그림은 **실제 UI/기능 스크린샷이 아닌 디자인 목업**. 원본 목업 이미지는 GitHub에 업로드하지 않았으므로 이 문서는 텍스트 기준이다. 비교는 실제 실행 후 스크린샷 파일과 출처 SHA를 추가한다.

| ID | 목업의 약속 | MVP 실제 목표 | 현재 실물 평가 | 후속 보강 |
|---|---|---|---|---|
| V01 | 고객이 바로 PDF 불러오기 | 1클릭/드래그 PDF 열기 + 미지원 경고 | NOT TESTED | 전용 홈·최근문서 |
| V02 | 왼쪽 문서함, 중앙 A4, 오른쪽 스타일 선택 | 3영역 데스크톱 UI / 읽기 쉬운 한글 | NOT IMPLEMENTED in commercial | 썸네일·반응형·키보드 |

## 매 반복 사이클 증거 템플릿
- 날짜(KST), 대상 브랜치 HEAD, 실행 명령/환경, 실제 화면캡처 및 실제 PDF 링크/로컬 비공개 경로, 원본 목업 대비 기능별 OK/GAP/NOT RUN.
- 첫 MVP에서는 갭을 전부 제거하지 않고 **1) 구매자 사용 흐름 차단, 2) 원문 오염/출력 실패, 3) 디자인 미관** 순서로 Top 5만 개선한다.
- 이미지만 새로 생성해 점검 항목을 OK로 표기하는 행위 금지. **실제 앱 캡처와 파일**만 근거로 인정.
