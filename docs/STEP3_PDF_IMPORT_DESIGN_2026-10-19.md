# STEP 3 — 기존 PDF 가져오기: 실행 설계·검증 계약 (2026-10-19)

> **단계:** STEP3 시작. 본 문서는 **구현/검증 계획**이며 코드의 완료를 뜻하지 않는다. `main`과 STEP1/2 기존 저장 데이터는 수정하지 않는다.

## 1. 기준
- 원본 우선: `docs/ASTRA_ORIGINAL_ROADMAP.txt` §5 STEP3 및 공통 원칙. 지원 대상은 **텍스트 선택 가능한 단일 열 PDF**. 텍스트·위치/출처, 문서 순서·타입 추정, 사용자 원본 대조·수정, 테마/재출력.
- **스캔 PDF OCR, 복잡한 표·다단 복원, 원본 레이아웃·페이지 수 동일 보장, PDF 모든 그래픽 직접 편집은 제외.** 추출 부족/불확실한 문서는 성공인 척하지 않고 경고·수동 검수를 거쳐야 한다.
- 원본 PDF는 로컬 파일 객체로만 읽고 외부 전송·콘솔 로그 기록·IndexedDB에 원본 파일 복제하지 않는다. 사용자가 확정하기 전에 기존 문서함/활성 문서는 쓰기 변경 없음.
- 자동으로 문장·숫자·기호를 수정/요약하지 않는다. PDF 텍스트 연산자가 제공하는 문자열을 원문으로 삼되, 시각적 줄/문단 재구성 과정에서 발생할 수 있는 공백·읽기순서 오차는 **원본 대조가 필요함**을 명시.

## 3. 우선 구현하는 세로형 MVP
1. PDF 파일(확장자/매직헤더 검사, 크기/페이지 제한) 업로드 → 오직 브라우저 메모리에서 `getDocument`으로 파싱, 기본 페이지 수·문자 추출 상태·이미지 존재 위험 표시.
2. `TextItem`의 글자·좌표·크기로 위→아래/좌→우 읽기 순서를 추정, 단일 열일 때 줄/문단 결합; 제목·본문·작은 캡션은 **추정**으로 표시. 각 블록에 `origin: {page, x,y,width,height}` 메타데이터 선택 저장. 값은 비신뢰 입력으로 검증.
3. **결과 확인 화면**: 로컬 원본 PDF 뷰어(임시 object URL)와 추출 텍스트, 추정 블록 타입·원본 페이지 번호·순서 ↑↓·본문 수정을 함께 표시. 원본을 저장·복제·외부 전송하지 않음.
4. 사용자 확인 후 기존 `ProjectDocument`(schemaVersion 2)의 **별도 새 문서**로 저장하며 기존 활성 문서/이미지는 그대로 보존. 1회 IndexedDB 트랜잭션으로 문서+active marker commit, 실패 시 원본 변경 없음. STEP2 문서 편집·테마·PDF 인쇄 렌더러를 그대로 사용.
5. 스캔/텍스트 없음, 암호화, 복잡한 다단·표 가능성, PDF 이미지/도형이 있으나 자동 재구성되지 않음 등의 조건은 **검증 필요** 또는 **지원하지 않음**으로 표시. 빈 문서·추출 0건은 성공 처리 금지.

## 4. 데이터 호환 계약
- STEP2 `ProjectDocument.schemaVersion = 2` 유지. 텍스트 블록 `origin?`은 선택 사항이며, 기존 schema2 자료와 JSON 백업의 유효성 유지. 이미 존재하는 STEP1의 v1 localStorage는 자동 변경/삭제하지 않음.
- 출처 좌표는 원본 페이지 viewport 기준 **PDF 점 단위의 좌상단** [x,y,width,height], 페이지 번호는 1부터. 사용자가 순서를 옮겨도 출처 페이지·좌표는 그대로 보존.
- 기존 저장소(IndexedDB `astra-pdf-redesigner:v2`)와 기존 이미지 assets 구조는 유지. 새 문서의 `source`는 PDF 원본 파일 바이트를 저장하지 않고 이름과 페이지 수/경고만 저장하거나 메모리에 유지.
- PDF 이미지의 복원/표 완전 재구성은 1차 작업의 통과 조건이 아니다. **이미지 존재를 무시하고 완전한 재디자인이라고 보고하지 않는다**.

## 5. 자동 테스트 및 인수 범위
- 기존 Node16/16 + STEP1/STEP2 Chrome·Edge PDF/IndexedDB 회귀 검사와 V1 마이그레이션/실제 2탭 충돌 방지를 모두 유지.
- 새로운 단위 테스트: 한글 및 숫자·특수문자 보존, 단일 열 좌표 정렬, 폰트 기반 제목/캡션 추정, 빈 페이지·열/이미지 경고, 차단 조건.
- 새로운 실브라우저 검사: 합성 선택 가능한 PDF → PDF import → 원본과 텍스트/문단/출처를 대조 → **확정 이전 문서함 변경 없음** → 확정 시 새 문서만 생성 → 테마 변경·리로드·A4 PDF 출력. 암호/스캔 PDF·실제 가변 PDF는 별도 테스트.
- **실사용 검증 기준:** 사용자 단순 PDF 5~10개에서 원본/추출 대조, 오인식·순서 오류 직접 보정·테마 재출력. 이 검증 없으면 STEP3 전체 PASS 선언 금지.
- STEP2 Windows Edge 육안 미완료 사항은 STEP3 진행과 독립된 미해결 체크리스트로 계속 유지.
