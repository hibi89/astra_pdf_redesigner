## 정확한 한계
- '4단계 기능'은 **탐색+포커스 안내**이며 데이터 유효성 전체를 강제하는 상태 기계나 완벽한 뒤로가기 위저드가 아님. 2단계는 세션 원본 필요; 재시작 후 원본은 다시 불러와야 하며 사용자의 바이트를 IDB에 몰래 영구 저장하지 않음.
- 원본 검수 n/N은 사용자 수동 표시(soft warning)이지 원문 전체 완전 보존/AI 자동 검사/판매 승인 아니다.
- 선택 가능한 텍스트 PDF 위주의 합성 검사만 통과. 고객 실제 PDF 5–10건과 일반 구매자 Windows PC, 코드서명/SmartScreen, 모델 CPU/RAM/한국어 품질, PDF 스캔 OCR·벡터·표 완전복원 검증은 하지 않음.
- **실제 오프라인 생성형 LLM 모델 배포 없음, `RELEASE_MANIFEST=null`; M03-B1 BLOCKED (소유자 승인·다운로드·라이선스/벤치 필요).** ₩30k/₩60k/₩90k 세 상품 모두 동일 AI라는 최종 목표 **미충족**, 판매 NO-GO.
