## 0. 제품 포지셔닝
'PDF를 꾸미는 편집기'가 아니라 **기존 PDF의 내용을 검수 가능한 형태로 보존하면서 새 디자인으로 다시 만드는 설치형 도구**. 고객의 성공 기준은 도구 기능 수가 아니라 지원 문서의 변환 성공률, 사용 시간, 정확한 결과물이다.
- 대상: 보고서·교육자료·제안서 제작자, 프리랜서, 소규모 조직.
- 비대상/초기 제외: CAD/도면, 계약서 원문 법적 동일성 보증, 암호·DRM PDF, 전자서명 보전, 고난도 스캔 OCR, 표·수식·다단 완전 재현, 인쇄소 CMYK/재단 전문 워크플로.
- 약속 문구: **지원하는 텍스트 중심 PDF의 의미·원문 내용을 유지한 새로운 조판**. 페이지 수·픽셀·글꼴·행갈이·표 배치 원본 동일은 약속하지 않는다.

## 1. 사용자 동선 / 화면 (4-step guided studio)
1. **PDF 열기**: 드래그앤드롭/파일 선택. 파일 크기·페이지 수·암호/스캔·벡터·표 의심 등 지원성 표시. 원본 절대 덮어쓰기 금지.
2. **원문 확인**: 좌측 **원본 PDF 실제 페이지 뷰**, 중앙 추출 블록/누락 목록; 우측 품질 점검 요약. 제목·문단·숫자·인용·그림/표 경고와 원본 위치 연결. '가져오기 확정' 전 프로젝트 영구 변경 금지.
3. **디자인 스튜디오**: 원본/결과 나란히, 중앙 결과 A4 미리보기, 우측 디자인 선택·색상·글꼴·레이아웃 옵션, 문단 클릭 직접 편집. **윤문 기본 OFF**. 사용자 선택 시 원문 블록별 변경 제안/전후 Diff → 채택/거부/되돌림. 어려운 블록은 원문 보존 및 경고.
4. **검수·PDF 저장**: 누락 의심/검증 실패가 남으면 눈에 띄는 보류. 모든 필수 항목 검수 후 새 파일명으로 로컬 PDF 저장, 열어 보기, 별도 원본 유지 프로젝트(.localdoc.json 등) 백업.

### 고정 UI 원칙
- 초보 사용자: '불러오기 / 내용 확인 / 디자인 / 내보내기' 4개 주요 탭, 도구·세부 설정은 보조.
- 원본과 결과 뷰는 같은 페이지·블록 ID로 연결. 직접 편집은 Undo/Redo, 선택·취소, 저장 오류 메시지 필수.
- 원문 유지·수정 제안 선택을 혼동시키지 않는다. 윤문 ON 표시/변경 건수/승인 대기 건수 상시 표시.
- 키보드 접근 가능, 창 900px 이상에서 정돈된 UX, 인쇄 A4에서 편집 UI 숨김; 국문 표시 정상.
- 이미지 목업은 비주얼 목표일 뿐 동일 구현/인쇄 품질 증거가 아니다. 실제 캡처·PDF 비교만 ACCEPTED.

## 3. 윤문 UX 계약
- 기본 **윤문 안 함**. '규칙 검수'로 단순 감지·안전한 규칙 수정을 제안할 수 있지만 그것을 로컬 LLM '정밀 윤문'과 동일하게 광고하지 않는다.
- 고객이 로컬 모델 패키지를 설치하면 네트워크·API 키 없이 정밀 윤문 실행. 최초 설치 용량과 최소 권장 PC를 사전 고지. 모델 없는 PC에서도 PDF 변환과 규칙 검사 정상 사용.
- 원문→수정 제안은 **블록 단위 diff**. 채택 전에: 숫자·날짜·금액·단위·이름·인용문·표 셀·링크·서법/양태 내용 정합 검사. 위험 시 원문 복원·수동 승인.
- 프롬프트로 100% 의미보존을 보장한다고 주장하지 않는다. 합격 판정 없는 수정안은 자동 적용 금지. 문서 전체 무단 자동 고치기 금지.
